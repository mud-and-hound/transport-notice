# แนบไฟล์ได้เลยครับ 📎

วางไฟล์ต่างๆ ไว้ในโฟลเดอร์นี้ (ลากไฟล์จากเครื่องมาวางใน VS Code ได้เลย)

| ไฟล์ที่รอ | ใช้ทำอะไร |
|---|---|
| ไฟล์ **All** (.xlsx) — Sheet **Shop** | รายชื่อสาขาทั้งหมด → นำเข้าตาราง `transport_branches` ให้ช่อง "สาขา" ค้นหาได้ |
| ฟอร์ม **ใบแจ้งงานขนส่ง SST** (.xlsx) | ต้นแบบหน้าตา/คอลัมน์ ให้เว็บตรงกับ Excel |

> ไฟล์ในโฟลเดอร์นี้ **ไม่ถูกส่งขึ้น GitHub** (ตั้งไว้ใน `.gitignore`) — ข้อมูลบริษัทอยู่ในเครื่องเท่านั้น
